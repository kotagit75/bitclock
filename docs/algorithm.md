# The algorithm
## Concepts
### Count
`count` is the local time maintained by the node.
### Stamp
A stamp is a timestamp generated by a node.
Stamps are defined as follows:
```
struct Stamp {
    address,
    count,
    public key,
    nonce,
    id,
    sign,
}
```

#### address
`address` refers to the address of the node that issued the stamp.
#### count
Set the value of `count+1` when a node generates a stamp.
#### public key
BitClock uses public keys to identify timestamps. By adding the public key which serves as an identifier  to stamp, the stamp can be identified.
#### nonce
`nonce` is the result of the Proof of Work.
#### id
A node can generate multiple stamps for the same timestamp. The `id` is used to distinguish between them.
#### sign
`sign` is created by the node that generated the stamp.
